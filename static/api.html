Pommeraie API

REST API for querying the Apple product database. All responses are JSON.

Categories

GET /api/categories

List all product categories with item counts.

Example
curl http://localhost:8080/api/categories
Response
[
  { "name": "iMacs", "count": 54 },
  { "name": "MacBookPros", "count": 87 },
  { "name": "Phones", "count": 46 },
  ...
]
GET /api/categories/{name}

List all items in a category. Returns an array of item summaries sorted newest-first.

Path Parameters
name Category name exactly as returned by /api/categories.
Example
curl http://localhost:8080/api/categories/MacBookPros
Response
[
  {
    "uuid": "F3A1B2C4-...",
    "modelName": "MacBook Pro (16-inch, M4 Max, Nov 2024)",
    "introduction": "November 8, 2024",
    "supportStatus": "Supported",
    "sortDate": 20241108
  },
  ...
]

Items

GET /api/items/{uuid}

Get the full detail record for a single item by its UUID. Returns every field from the plist.

Path Parameters
uuid Item UUID from a category listing or search result.
Example
curl http://localhost:8080/api/items/F3A1B2C4-...

Search

GET /api/search?q=...

Full-text search across all product names. Also matches order numbers, family numbers, and machine IDs. Results are sorted newest-first.

Query Parameters
q Search query (case-insensitive).
Example
curl "http://localhost:8080/api/search?q=MacBook+Pro"

Model Lookup

GET /api/lookup?q=...

Smart lookup by order number, family number, or machine ID. Returns the full detail record for the first match.

Query Parameters
q Order number (e.g. MX2E3LL/A), family number (e.g. A3401), or machine ID (e.g. Mac16,8).
Example
# Look up by order number
curl "http://localhost:8080/api/lookup?q=MX2E3LL/A"

# Look up by machine ID
curl "http://localhost:8080/api/lookup?q=Mac16,8"

Filter

GET /api/filter?field=...&op=...&value=...

Dynamic filtering across items by any plist field. Returns matching item summaries sorted newest-first.

Query Parameters
field Plist field name (e.g. SupportStatus, Processor).
op Comparison operator (see table below).
value Value to compare against.
categories Optional. Comma-separated list of categories to search within. Defaults to all.
Filter Operators
Operator Description
eq Exact match (case-insensitive)
contains Substring match (case-insensitive)
prefix Starts with (case-insensitive)
regex Go regular expression match
gt Greater than (numeric or lexicographic)
lt Less than (numeric or lexicographic)
Examples
# Find all currently supported products
curl "http://localhost:8080/api/filter?field=SupportStatus&op=eq&value=Supported"

# Find products with M4 processors
curl "http://localhost:8080/api/filter?field=Processor&op=contains&value=M4"

# Filter within specific categories
curl "http://localhost:8080/api/filter?field=SupportStatus&op=eq&value=Supported&categories=MacBookPros,iMacs"

Multi-Category

GET /api/multicategory?names=...

Merge items from multiple categories into a single sorted list.

Query Parameters
names Comma-separated category names.
Example
curl "http://localhost:8080/api/multicategory?names=iPads,iPadPros,iPadAirs"

Status & Configuration

GET /api/status

Server status: whether data is loaded, category/item counts, version info, and build metadata.

Example
curl http://localhost:8080/api/status
Response
{
  "loaded": true,
  "categories": 24,
  "items": 4231,
  "version": "0.1.0",
  "build": { "go": "go1.23.0", "commit": "abc1234..." }
}
GET /api/sideboard

Returns the sidebar navigation configuration (sideboard.json), which defines category groups, filters, and display rules used by the web UI.

Example
curl http://localhost:8080/api/sideboard

CLI Usage

You can also dump the entire database as JSON for local processing with jq or other tools: 
./pommeraie -json | jq '.iMacs | length'
